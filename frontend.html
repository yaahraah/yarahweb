Front-End Development

Creating the visual and interactive parts of a website.

What is Front-End Development?

Front-End Development focuses on the visual and interactive parts of a website that users can see and use. It involves technologies such as HTML, CSS, and JavaScript to create the structure, appearance, and functionality of a website.

My Experience with Front-End Development

Based on my experience using HTML and CSS, I find web development fun and interesting, although it can also be quite complex. Creating different layouts and designs allows me to explore my creativity while learning how websites are structured.

Career Thoughts

I see Front-End Development as a possible backup career. Although it is not currently my first choice, I am open to exploring this field and improving my abilities.

Skills I Want to Develop

I want to improve my coding skills, particularly in HTML, CSS, and other programming technologies that can help me create better and more functional websites.

Expected Challenges

I expect to encounter errors and difficulties when learning new concepts. Understanding unfamiliar coding techniques and finding solutions to errors may also be challenging.

Technologies Used

HTML

Creates the structure and content of a webpage.

CSS

Controls the design, colors, layout, and appearance of a webpage.

JavaScript

Adds interactive features and functionality to a website.

Conclusion

Front-End Development combines creativity and technical skills to create websites that are visually appealing and easy to use. Although it can be challenging, learning more about it can help me improve my coding abilities and understand how websites work.
